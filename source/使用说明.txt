PDFMathTranslate 1.9.11  ——  PDF 文档翻译（Windows 64 位 便携版 · 中文界面）
================================================================

一、如何启动
1. 双击本文件夹中的 PDFMathTranslate.exe（或桌面 / 开始菜单里的
   "PDFMathTranslate" 快捷方式）。
2. 程序会打开一个黑色命令行窗口，并自动打开浏览器界面（地址类似
   http://127.0.0.1:7860/ ）。若浏览器没有自动打开，请手动在浏览器里访问
   该地址。
3. 黑色窗口就是程序本体，使用期间请不要关闭；关闭窗口即退出程序。

二、如何翻译
1. "输入方式" 选 "文件"，点 "PDF 文件" 框选中（或拖入）要翻译的 PDF；
   也可以选 "链接" 粘贴 PDF 链接。
2. "源语言" / "目标语言" 中选择语言，例如 English -> 简体中文。
3. "翻译服务" 默认已选好 Bing（免费、免注册、国内可直接使用）。
   若 Bing 不稳定，可切换 Google（国内一般需要代理）或其他服务。
4. 点 "开始翻译"。完成后页面下方 "翻译结果" 会给出两个 PDF 的下载：
   - 文件-mono.pdf：纯译文版（对应 "下载纯译文 PDF"）
   - 文件-dual.pdf：原文/译文双语对照版（对应 "下载双语对照 PDF"）
5. 下方的 "预览" 可以直接查看翻译后的页面效果。

三、可选设置（默认值一般够用）
- 页码：全部页面 / 仅第一页 / 前 5 页 / 自定义页码（如 1-3,5）。
- 线程数：默认即可，网络差时可调小。
- "展开更多实验性选项（进阶）"里还有：跳过字体子集化、忽略缓存（重新
  解析）、自定义公式字体正则、自定义 LLM 提示词、使用 BabelDOC 引擎等
  高级选项，不懂请保持默认。

四、进阶：需要 API Key 的服务
OpenAI、DeepSeek、智谱、Gemini、DeepL、Azure 等服务需要自己的 API Key，
选中对应翻译服务后会在界面中出现设置项，填写即可，配置会保存到：
    C:\Users\<你的用户名>\.config\PDFMathTranslate\config.json

五、常见问题
1. 双击没反应，或提示缺少 DLL / 无法启动
   先运行本文件夹里的 vc_redist.x64.exe 安装微软 VC++ 运行库，再重新双击。
2. 首次启动比较慢（约 1 分钟）
   程序要把自带的模型和字体解压到
   C:\Users\<你的用户名>\.cache\babeldoc ，之后启动会快很多
   （占用约 320MB 磁盘空间）。
3. 提示端口被占用
   程序会自动改用其它端口（如 7861），按黑窗口里显示的地址访问即可。
4. 翻译报 "Too Many Requests"、"sorry" 验证码或长时间无响应
   翻译服务被限流，换一个翻译服务（例如 Bing / Google 互换）或稍后再试。
5. 杀毒软件报毒
   PyStand 打包的 Python 程序常被误报，添加信任即可，本程序不含恶意代码。
6. 网页界面文字有英文？
   界面已整体汉化为中文（含系统组件文案）。若个别按钮仍显示英文，多为
   该服务（如 OpenAI）的自带设置项，不影响使用。
7. 想卸载
   本软件为绿色便携版，删除整个文件夹即可；缓存在
   C:\Users\<你的用户名>\.cache\babeldoc ，配置在
   C:\Users\<你的用户名>\.config\PDFMathTranslate ，可一并删除。

六、文件说明
PDFMathTranslate.exe            主程序，双击启动
创建桌面快捷方式.bat            重新生成桌面快捷方式（快捷方式丢了时用）
_pystand_static.int             启动脚本（请勿删除）
runtime\                        内置 Python 3.12 运行环境（请勿删除）
site-packages\                  程序依赖库（请勿删除）
offline_assets_*.zip            自带的模型与字体包（首次启动后仍建议保留）
vc_redist.x64.exe               微软 VC++ 运行库（无法启动时安装）
使用说明.txt                    本文件

七、命令行用法（可选）
把 PDF 拖到 PDFMathTranslate.exe 上，或在命令行中运行：
    PDFMathTranslate.exe 论文.pdf -s bing -lo zh -o 输出目录
    PDFMathTranslate.exe --help
