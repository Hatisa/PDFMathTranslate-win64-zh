# PDFMathTranslate 中文便携版（Windows x64）

基于开源项目 [PDFMathTranslate](https://github.com/PDFMathTranslate/PDFMathTranslate) **v1.9.11** 的 Windows 便携版重打包，界面完整汉化，开箱即用。

> 本项目不是官方发行版，只是社区汉化 + 便携打包。翻译能力全部来自上游项目；问题请优先参考上游文档。

## 下载

到 [Releases](../../releases) 页面下载：

| 文件 | 大小 | 说明 |
|---|---|---|
| `PDFMathTranslate-1.9.11-win64-zh.zip` | 约 640 MB | 完整便携包，解压即用（含内置 Python 运行环境、检测模型与字体） |

要求：Windows 10/11 64 位。若双击无法启动，先安装解压目录里的 `vc_redist.x64.exe`（微软 VC++ 运行库）。

## 使用

1. 解压到任意目录（路径不含中文更稳妥），双击 `PDFMathTranslate.exe`。
2. 黑色命令行窗口是程序本体，**使用期间不要关闭**；程序会自动打开浏览器界面（默认 <http://127.0.0.1:7860/>，端口被占用时自动顺延）。
3. 「输入方式」选「文件」→ 选择一个 PDF；选「源语言 / 目标语言」，例如 English → 简体中文。
4. 「翻译服务」默认 **Bing**（免费、免注册、国内可直接使用）。
5. 点「开始翻译」，完成后在「翻译结果」下载：
   - `xxx-mono.pdf`：纯译文
   - `xxx-dual.pdf`：原文 / 译文双语对照

首次启动会把自带的检测模型与字体解压到 `%USERPROFILE%\.cache\babeldoc`（约 320 MB），因此第一次启动较慢，之后启动很快。

更多说明见压缩包内的 `使用说明.txt`。

## 本版相对上游的改动

1. **界面汉化**：全部标签、按钮、提示、错误信息改为中文；语言 / 页码下拉框采用「中文显示、英文取值」，翻译逻辑保持一致。
2. **框架组件中文化**：汉化 Gradio 自带的组件文案（拖放提示等），即使浏览器是英文环境也显示中文界面。
3. **默认翻译服务改为 Bing**：Google 翻译在国内常被限流（HTTP 429 / 验证码），Bing 免密钥可用；Google 仍在列表中可切换。
4. **启动器改进**：自动寻找 7860–7889 中的空闲端口；首次启动自动还原离线模型与字体包；出错时打印完整错误并在窗口停留，不再一闪而过；`--help` 显示正确的程序名。
5. **附带 `vc_redist.x64.exe` 与 `创建桌面快捷方式.bat`**，方便离线环境部署。

改动细节与对应源码见 [`source/`](source/) 与 [SOURCE.md](SOURCE.md)。
